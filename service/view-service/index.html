System Assets / Coin & Bar Vision

            
Put files inside system_assets in the project folder, then scan. Subfolders are included.

            
            

            

            
            
            

              
              
              
              
              
              
            

            
Vision notes
Coin and bar only. Keep the complete item inside the ROI. Low confidence stays Unknown. No detections do not prove an empty pan. This model identifies shape; it does not determine gold purity. Switch YOLO off to use the existing manual/OpenCV workflow.

            

            
Geometry: empty-support reference
              
Keep the support flat, camera nearly overhead, and ROI free of objects. Recalibrate after camera restart, movement or ROI changes. This does not zero the scale.

              
              
              
              
              

              
Geometry quality settings
                
                
                
Height is tray-relative, not camera range. Density compares only with the configured pure-gold reference; it does not prove purity.

              

            

            
Known-gold 916/999 reference model
              
Uses raw F1–F4 RMS changes, formula area, thickness and shape. This is reference matching only; it cannot identify non-gold.

              
              
              

              
              

                
                
                
              

              

              
The supplied bundle needs scikit-learn 1.6.1 in View Python. Run fresh four-frequency air calibration after updating. Simulated readings cannot become accepted physical matches.

            


            
Legacy Gold Standard model pair
              
These selectors use the existing Gold Standard classifier. They do not select that mode automatically. Only frequency_rf_v1 bundles with the documented feature order can be activated.

              
              
              
              

            

            
API sources and formats
              
Service addresses, price/FX URLs and JSON field paths. Rates use USD per troy ounce and MYR per USD. Edits apply to the next request or price refresh.
