Place transparent 128x128 PNG carousel assets here.

Expected filenames:

- `gold-24k.png`
- `gold-22k.png`
- `gold-18k.png`
- `silver-999.png`
- `silver-925.png`
- `palladium.png`

The HMI will use these images when present. If an image is missing, the CSS bar fallback remains visible.

Optimized display copies may be generated as:

- `gold-24k-display.png`
- `gold-22k-display.png`
- `gold-18k-display.png`
- `silver-999-display.png`
- `silver-925-display.png`
- `palladium-display.png`
